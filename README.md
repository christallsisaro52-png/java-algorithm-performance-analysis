# Java Algorithm Performance Analysis

This project compares the performance of different sorting algorithms implemented in Java.

## Algorithms Tested

- Bubble Sort
- Insertion Sort
- Merge Sort
- Java Built-in Sort

## Data Structures

The algorithms were tested using:

- ArrayList
- LinkedList

## Project Purpose

The purpose of this project was to analyse and compare the performance of different sorting algorithms across different input sizes.

## Performance Testing

The program runs repeated experiments and records the average execution time for each algorithm.

The results were stored in a CSV file and used to compare the empirical performance of the algorithms.

## Visualisation

MATLAB was used to generate graphs showing how execution time changes as the input size increases.

## Technologies Used

- Java
- IntelliJ IDEA
- MATLAB
